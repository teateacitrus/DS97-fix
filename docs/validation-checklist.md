# Validation Checklist

- [ ] オリジナルBIN/CUEをバックアップした
- [ ] メモリーカードをバックアップした
- [ ] 入力SHA-256が一致した
- [ ] スクリプトが正常終了した
- [ ] 変更LBAが想定どおりだった
- [ ] EDC/ECC検証が成功した
- [ ] 出力CUEから起動した
- [ ] ゲームが起動した
- [ ] レースが開始した
- [ ] 勝利後に停止しなかった
- [ ] 牧場へ戻れた
- [ ] 次週へ進めた
- [ ] ゲーム内セーブができた
- [ ] 再起動後にセーブを読み込めた
- [ ] 複数回の勝利を確認した

注: 勝利後停止回避はno$psX 2.3でruntime-confirmedです。一方、長期運用、正常なsave/reload、繰り返し勝利、別エミュレーター動作は未確認です。
