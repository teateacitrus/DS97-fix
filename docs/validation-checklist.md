# Validation Checklist

- [ ] オリジナルBIN/CUEをバックアップした
- [ ] メモリーカードをバックアップした
- [ ] 入力SHA-256が一致した
- [ ] スクリプトが正常終了した
- [ ] 変更LBAが想定どおりだった
- [ ] EDC/ECC検証が成功した
- [ ] 出力CUEから起動した
- [ ] ゲームが起動した
- [ ] レースが開始した
- [ ] 勝利後に停止しなかった
- [ ] 牧場へ戻れた
- [ ] 次週へ進めた
- [ ] ゲーム内セーブができた
- [ ] 再起動後にセーブを読み込めた
- [ ] 複数回の勝利を確認した
- [ ] no$psXを完全終了してからMCDを操作した
- [ ] 元の正常なMCDをバックアップした
- [ ] パッチ済みイメージのbasenameに対応するMCDを確認した
- [ ] 必要に応じてコピー元とコピー先のSHA-256が一致した
- [ ] 電源投入状態からパッチ済みCUEを起動した
- [ ] ゲーム内から既存牧場をロードできた
- [ ] ロード直後にゲーム内セーブできた
- [ ] 勝利後に牧場へ戻れた
- [ ] 勝利後にゲーム内セーブできた
- [ ] 複数回の勝利後も正常に進行した
- [ ] DuckStationで勝利後停止を回避できた
- [ ] 長期運用は未確認であることを理解した

注: 勝利後停止回避はno$psX 2.3とDuckStationでruntime-confirmedです。正しいMCDを割り当てた状態での既存牧場ロード／保存と、複数回勝利後の進行も確認済みです。一方、長期運用は未確認です。
